# Лабораторная работа №1

Тема: Настройка среды разработки. Первая программа.

Цель работы: Освоить среду разработки (IDE), научиться создавать,
компилировать и запускать простые программы на C++. Получить
первый практический опыт работы с потоковым выводом cout и
вводом cin.

## Ход работы:
Вариант №4, базовый, средний и повышенный уровни сложности.

| Уровень сложности |Задача                                                                |
| ----------------- | ------------------------------------------------------------------ |
| Базовый | Объём куба |
| Средний | Запросить два числа, вывести сумму, разность, произведени |
| Повышенный | Запросить радиус → площадь сектора (угол задаётся в градусах) |

# Лабораторная работа №2

Тема: Переменные и арифметические операции.

Цель работы: Научиться объявлять переменные базовых типов
(int, double, float, char, bool), выполнять арифметические операции (+, -
, *, /, %), правильно выбирать тип данных в зависимости от решаемой
задачи, понимать механизмы явного и неявного приведения типов, избегать
потери точности при вычислениях, корректно работать с целочисленным и
вещественным делением.

## Ход работы:
Вариант №4, базовый, средний и повышенный уровни сложности.

| Уровень сложности |Задача                                                                |
| ----------------- | ------------------------------------------------------------------ |
| Базовый | Перевести метры в сантиметры |
| Средний | По трём оценкам вычислить средний балл. |
| Повышенный | Вычислить корни квадратного уравнения. Обработать все случаи. |
